# Projet-de-recherche-Battage-de-cartes
Projet réalisé durant ma deuxième année d'études supérieures. Son but était de modéliser et de simuler différents algorithmes de battage de cartes pour analyser leur efficacité, c'est-à-dire déterminer le nombre de battages nécessaires pour qu'un jeu de N cartes soit considéré comme "parfaitement mélangé" (mélange uniforme).
